# Well-Known Endpoints Documentation

This document provides an overview of the Well-Known endpoints in the `crewmgrservice` application. These endpoints are used for specific purposes such as app linking.

---

## **1. Asset Links**

- **URL**: `/.well-known/assetlinks.json`
- **Method**: `GET`
- **Description**: Provides the `assetlinks.json` file for app linking.
- **Response**:
  - JSON object containing asset links.
- **Usage**:
  Send a `GET` request to retrieve the `assetlinks.json` file.
